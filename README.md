# 🎮 Tetris (HTML5 + JavaScript)

브라우저에서 바로 실행 가능한 **HTML5 테트리스 게임**입니다.  
Canvas와 순수 JavaScript로 구현되었으며, **점수판 / 레벨 시스템 / 진동 효과**를 포함합니다.

---

## 📌 주요 기능

- ✅ 테트리스 기본 규칙 구현
- 🧮 점수 시스템
- 📈 레벨 시스템 (속도 증가)
- 🧱 줄 제거 감지
- 📳 진동 효과 (모바일 지원)
- ⌨️ 키보드 조작
- 🌐 설치 없이 브라우저 실행

---

## 🕹️ 조작 방법

| 키 | 동작 |
|---|---|
| ⬅️ | 왼쪽 이동 |
| ➡️ | 오른쪽 이동 |
| ⬇️ | 소프트 드롭 |
| ⬆️ | 블록 회전 |
| Space | 하드 드롭 |

---

## 📱 진동(Vibration) 기능

- 줄 제거 시: **짧은 진동**
- 하드 드롭 시: **아주 짧은 진동**
- 모바일 브라우저에서만 동작
- PC 환경에서는 자동 무시됨

navigator.vibrate(100);
